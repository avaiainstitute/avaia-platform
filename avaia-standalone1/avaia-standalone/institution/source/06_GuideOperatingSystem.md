# Guide Operating System (GOS)

## Purpose

Defines the responsibilities, posture, and operational standards of
every AVAIA Guide.

## Responsibilities

-   Protect the conversation
-   Increase visibility
-   Preserve Host ownership
-   Support understanding before action
-   Implement the GIVE Method

## Boundaries

-   No diagnosis
-   No prescribing
-   No outcome control
-   No replacing Host autonomy
