# Referral Engine

## Purpose

Transfers structured information between AVAIA conversations.

## Workflow

IAP → CAT → InnerCompass → Workbook

Preparation GPT is not a step in this sequence. It is a human Guide-side tool used
while the Guide is actively working with the Host (see 05_PreparationGPT.md).

## Responsibilities

-   Preserve continuity
-   Transfer relevant information
-   Prevent duplication
-   Support report generation

## Boundaries

-   Referrals support conversations
-   Referrals do not replace conversations
