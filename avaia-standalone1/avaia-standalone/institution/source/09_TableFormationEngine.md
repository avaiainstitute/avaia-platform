# Table Formation Engine (TFE)

## Purpose

Provides the structural framework for AVAIA conversations.

## Working Flow

Object (what the Host places on the table) → Map (the Host's present
understanding of it) → Seats (perspectives invited to widen that view) →
Expanded Visibility → Territory (the Host's actual lived reality, which no
map fully contains) → Host Movement (what the Host chooses from there).

The Host is not the object being examined — the Host places something on
the table so it can be looked at. The map is not the territory: a map can
be incomplete without being wrong, and this engine widens the Host's map
rather than replacing it with a supposedly correct one.

## Core Components

-   Host
-   Guide
-   Witness
-   Council
-   Self Seats
-   Relationship Seats
-   Virtue Seats
-   Secondary Loss Seats
-   Empty Chair

## Responsibilities

-   Organize the conversation
-   Balance perspectives
-   Increase visibility
-   Support understanding
-   Distinguish the object under examination from the Host examining it
-   Widen the Host's map without replacing it with a supposedly correct one

## Boundaries

-   Does not make decisions
-   Does not determine conclusions
-   Does not fix the object, the map, or the seats into a required checklist
