# Individual Awareness Profile (IAP)

## Purpose

The Individual Awareness Profile is the first core conversation in the
AVAIA Journey. Its purpose is to establish awareness and prepare the
Host for deeper understanding.

## Position

Preparation GPT → IAP → CAT

## Primary Objectives

-   Establish awareness
-   Identify presenting concerns
-   Recognize themes
-   Observe fragmentation
-   Prepare referral to CAT

## Inputs

-   Host conversation
-   Guide observations

## Outputs

-   Awareness summary
-   Themes
-   Referral to CAT

## Boundaries

-   No diagnosis
-   No prescribing
-   No premature conclusions
